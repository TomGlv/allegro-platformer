# allegro-platformer

> 2D platformer in C with Allegro 4: sprites, gravity, jumping, scrolling backgrounds (two iterations).

- `v1/` — player sprites (idle / left / right), gravity and jump physics, ground collision
- `v2/` — more backgrounds and levels

## Build
Allegro 4 + CMake (CLion). Sprite paths are set at the top of `main.c`.
